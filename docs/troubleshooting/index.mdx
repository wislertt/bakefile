Fixes for the errors bakefile users hit most. Each page shows the exact error, the cause, and the fix.

## Errors

- [`bake: command not found`](/troubleshooting/command-not-found) - bakefile not installed, or its bin directory missing from PATH.
- [`BakebookError: No 'bakebook' found`](/troubleshooting/bakebook-not-found) - bake cannot find the bakebook variable.
- [Bakebook must be a Bakebook, got Typer](/troubleshooting/wrong-bakebook-type) - the bakebook variable is not a Bakebook instance.
- [Directory not found and file name errors](/troubleshooting/file-name-errors) - `-f` takes a file name, never a path.
- [Failed to load bakebook after dependency sync](/troubleshooting/import-errors) - imports fail after `uv sync`.
- [Tasks use the wrong Python interpreter](/troubleshooting/wrong-python) - module importable in your shell but not from a task.

## Commands print but never run

Dry-run mode (`bake -n`) prints commands instead of executing them. Remove `-n` to run for real. To force specific commands to execute even under dry-run, use `override_dry_run` (see [Context](/concepts/context)).

## Completion not working

```bash
bake --install-completion
```

Then restart the shell or open a new terminal.

## Log output too noisy or too quiet

Tune levels per logger with `BAKE_LOG`, bump verbosity with `-v`, and switch to JSON logs with `--no-log-pretty`. See [Logging](/usage/logging).

## Secrets print as `**********`

Masked by design. `SecretStr` values stay hidden in `bakefile env` and `bakefile export` until you pass `-s` / `--secret`. See [Settings](/usage/settings).
