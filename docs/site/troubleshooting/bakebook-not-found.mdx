---
title: "BakebookError: No 'bakebook' found"
sidebarTitle: Bakebook not found
description: bake cannot find a bakebook variable. Name the variable bakebook, select one with -b, or point bake at the right file with -C, -f, or -g.
---

`bake` looks for a variable named `bakebook` (the default) and did not find one.

```
BakebookError: No 'bakebook' found in /path/to/project/bakefile.py
Searched in: /path/to/project
```

## The variable has a different name

Select it with `-b`:

```bash
bake -b my_bakebook build
```

## bake loaded a different file

`bake` uses the nearest `bakefile.py` walking up from the current directory, else the Global `bakefile.py`. The path in the error is the file it loaded. If that is not the one you meant, pick a directory with `-C`, another file name with `-f`, or the Global `bakefile.py` with `-g`:

```bash
bake -C /path/to/project build
bake -f tasks.py build
bake -g build
```

See [Finding bakefile.py](/usage/finding-bakefile).

## The file does not define a bakebook

Check the file actually defines and instantiates the bakebook:

```python
from bake import Bakebook

bakebook = Bakebook()
```

See [Bakebook](/concepts/bakebook) for how bakebooks are defined.
